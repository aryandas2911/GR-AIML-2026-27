# Task 2

## Overview
The objective of this project was to build a simple house price prediction model using Python and NumPy. The model predicts the price of a house based on its size in square feet.

## Approach
Prepared house size and price data.
Split the dataset into training and testing sets.
Implemented Linear Regression using the closed-form solution.
Predicted house prices, including for a 1,300 sq ft house.
Evaluated model performance using MAE and MSE.
Added user input for interactive price prediction.
Tech Stack: Python, NumPy

## Files
solution.ipynb — Jupyter Notebook containing the code and results.
Numpy house prediction.pdf — Report explaining the solution and findings.
