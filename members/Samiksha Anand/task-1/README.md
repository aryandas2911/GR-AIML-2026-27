# Task 1

## Overview
SafeTime is a proposed AI/ML system that estimates the crime risk level of a particular location at a specific time using historical crime data.

## Approach
1. Data Collection: Collect historical crime data containing crime type, location, date, and time.
2. Data Analysis: Identify patterns in crime incidents across different locations, times, and days.
3. ML Model: Train a supervised classification model, such as Random Forest, to estimate Low, Medium, or High crime risk.
4. Testing: Evaluate the model on unseen data to check prediction accuracy and reliability.
5. Final Product: Build a simple website where users enter a location and time to view the estimated crime risk.
Core idea: Use machine learning to learn from historical crime patterns and estimate risk for a specific location and time.
