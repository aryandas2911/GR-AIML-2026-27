House Price Prediction

This project is a foundational machine learning script that implements simple linear regression from scratch using NumPy. It establishes the mathematical relationship between house size and price without relying on high-level machine learning libraries like Scikit-Learn.

Tasks Completed in this Project:
Data Handling: Structured, reshaped, and appended numerical arrays using core NumPy functions.
Statistical Analysis: Computed mean, median, standard deviation, and analyzed the impact of extreme outlier values on central tendencies.
Algorithm Implementation: Manually calculated the slope ($w$) and intercept ($b$) for a simple linear regression model using mathematical formulas on the training data.
Model Evaluation: Performed a manual 80/20 train-test split and evaluated the model's accuracy using Mean Absolute Error (MAE) and Mean Squared Error (MSE).
Interactive Interface: Built a command-line input loop allowing users to input custom house sizes for real-time price predictions.
Dataset Randomization: Applied random seed permutations to accurately shuffle corresponding feature and target arrays.
